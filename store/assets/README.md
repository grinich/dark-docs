# Store artwork

Upload the PNG files as promotional artwork. The SVG files are editable sources.

| File | Size | Purpose |
| --- | --- | --- |
| `promo-small.png` | 440 × 280 | Small promotional tile |
| `promo-marquee.png` | 1400 × 560 | Optional marquee promotional image |

Both PNGs are opaque, 8-bit RGB images in sRGB. They were rendered from the accompanying original SVG artwork and visually checked at their final sizes. The design uses Dark Docs' charcoal palette and crescent-moon motif.

These are promotional illustrations, not screenshots of Google Docs. They contain no document content or Google logos. Add genuine, current screenshots of the extension in use separately for the store's screenshot fields. Use a non-sensitive sample document.

The sources use Helvetica Neue with Helvetica and Arial fallbacks. The included PNGs already contain the rendered typography; no font installation is needed to upload them.
